# Weekly Social Content Calendar Template

Last updated: 2026-03-20  
Time zone: Europe/Zurich (adapt per target market)

Use this template every week after running:

```bash
npm run marketing:weekly-batch
```

## Weekly Publishing Plan

| Day | TikTok | Instagram Reels | Pinterest | YouTube Shorts | CTA URL |
| --- | --- | --- | --- | --- | --- |
| Monday | Hook + product reveal | Reel cut of Monday TikTok | 1 product pin | 1 short version | `/create` |
| Tuesday | Prompt tip (how to ask AI) | Prompt tip remix | 1 style pin | - | `/create` |
| Wednesday | Before/after mockup | Product close-up reel | 1 mockup pin | 1 short version | `/products` |
| Thursday | Trend audio + product demo | UGC-style demo | 1 niche keyword pin | - | `/create` |
| Friday | Best seller spotlight | Best seller recap | 1 offer pin | 1 short version | `/products` |
| Saturday | Behind-the-scenes | Story-to-reel snippet | 1 lifestyle pin | - | `/create` |
| Sunday | Weekly recap + CTA | Weekly recap | 1 roundup pin | - | `/create` |

## Post Planning Fields (copy per post)

For each planned post, fill:
- Platform
- Publish date/time
- Content angle
- Prompt/design used
- Product featured
- Hook (first sentence)
- Caption
- CTA
- UTM URL
- Status (`planned`, `scheduled`, `published`)

## UTM Naming Standard

Use one format for all social links:

`https://smartprintai.com/create?utm_source=<channel>&utm_medium=social&utm_campaign=<yyyy-week>&utm_content=<post-slug>`

Examples:
- `utm_source=tiktok`
- `utm_source=instagram`
- `utm_source=pinterest`
- `utm_source=youtube`

- TikTok: 5 posts
- Instagram Reels: 5 posts
- Pinterest: 7 pins
